# Santosh Kumar Portfolio

This is my personal portfolio, which I have built to present my tech stack and my web development mindset in one clean experience.

This project is more than a static profile page. It is a frontend-focused portfolio designed to communicate how I approach UI polish, responsiveness, visual hierarchy, and user experience. The goal was simple: make the first impression feel intentional, fast, and memorable.

## Why This Project Stands Out

Most portfolio sites tell people what the developer can do.

This one tries to show it.

From the custom dark and light theme toggle to the animated hero, responsive project cards, structured tech stack section, and smooth navigation, every part of the interface is built to reflect practical frontend decision-making. The emphasis is on usability, clarity, and detail, because those are often the qualities that carry over best into real product teams.

## What’s Inside

- Responsive layout designed for desktop, tablet, and mobile
- Dark and light theme support with saved user preference
- Animated hero section with motion and visual depth
- About section with personal and professional context
- Tech stack grid with curated branding and consistent presentation
- Project showcase with clear descriptions, stack tags, and direct links
- Resume access and recruiter-friendly contact section
- Smooth scrolling navigation and section-based browsing

## What This Project Communicates

This portfolio is intentionally designed to signal the kind of teammate I aim to be:

- Someone who cares about the user-facing details, not just whether the code runs
- Someone who can take a plain interface and shape it into a stronger experience
- Someone who balances aesthetics with structure, readability, and maintainability
- Someone who treats even a personal project like a real product surface

That matters because good frontend work is rarely just about syntax. It is about judgment, consistency, and the ability to make technology feel approachable.

## Local Setup

Because this is a frontend portfolio project, setup is intentionally simple.

1. Clone the repository
2. Open the project folder
3. Run `index.html` in your browser

If you prefer using VS Code, the easiest path is to use a live preview extension such as Live Server.
